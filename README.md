# 🧪 Interactive Chemistry Lab

An interactive web-based chemistry learning platform designed to make chemistry more visual, engaging, and easier to explore.

## ✨ Features

* 🧪 Interactive Periodic Table
* 🔍 Element Search
* ⚛️ Detailed Element Information
* 🧬 Electron & Orbital Configurations
* 🌟 Element of the Day
* 🧮 Chemistry Calculators
* 📚 Chemistry Notes & Learning Resources
* 🌙 Dark & Light Mode
* 📱 Responsive Design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## 🎯 Project Goals

The goal of ChemLab is to create an interactive environment where students can explore chemistry concepts instead of only learning them from static textbooks.
